# Thư mục báo cáo

Mỗi người viết phần module của mình thành 1 file Markdown, đặt tên `NN_ten-module.md` (vd `04_khoahoc.md`), gồm:
1. Mô tả bảng và các cột
2. Ràng buộc (PK, FK, CHECK, trigger)
3. Các truy vấn/thủ tục chính và ví dụ chạy
4. Kết quả test (ảnh chụp hoặc trích output)

Tú tổng hợp thành báo cáo cuối. ERD và mô hình quan hệ đặt trong `docs/erd/`.
